Access

A verified email and owner approval are required. The initial tester limit is five, excluding the owner. Only the owner can expand it.

Chat and Studio

Sent chat text, usage information, preferences, Studio projects and saved versions are stored through NOIR’s existing backend and Supabase. Approved project members can read project content; only editors and owners can save changes. Invitations are email-bound, expire after seven days and can be revoked. Shared project content may already have been viewed or downloaded before access is removed.

AI and voice processing

AI requests send necessary conversation and authorized file context to the configured provider. Free models have availability and quota limits. Think requires a compatible free reasoning model. Browser speech recognition and some playback voices may use external processing. NOIR does not record or store raw audio. Voice is turn-based, not a live audio conversation.

Prototype previews

Frontend prototypes run in a sandbox with an opaque origin. They cannot access NOIR’s parent page or credential storage. Network requests, forms and external assets are restricted. There is no automatic website hosting or backend generation.

Usage and feedback

Normal quotas and rate limits apply to Chat, Think and Studio AI. Analytics use aggregated request counts and token totals, not full conversations. Feedback is sent only when you choose to submit it and is linked to your account for abuse prevention. Do not include credentials or sensitive information.

Beta limitations

AI answers can be wrong. Review generated content before relying on it. PDF exports are flattened images. Office compatibility, real microphone behavior and live-provider availability still require testing on your device. Collaborative saving uses version checks and polling, not shared live cursors.

Privacy and terms drafts are under owner review before a wider launch. Use the in-app Feedback control for questions or bug reports.
