# NOIR beta privacy draft — owner review required

This is a product-information draft, not a completed legal review. Before wider launch, confirm the operator/contact details, jurisdictions, legal basis, deletion/export procedures, processor terms and retention schedule.

NOIR uses its existing authentication and database services to store accounts, saved text chats, usage totals, preferences and private Studio projects. Request context goes only to the configured AI service when the user asks for a response. Necessary authorized Studio file content may be included. Third-party service policies and regional processing must be reviewed before expansion.

Voice is turn-based. Browser recognition and some synthesis voices can use external processing. NOIR does not capture or store raw audio. Sent transcripts become normal chat messages. Device voice/mute preferences are saved locally.

Studio files are private by default. Owners can invite verified, approved beta users as editors/viewers. Email-bound links expire after seven days; invitations and membership can be revoked. Revocation cannot retract previously downloaded content. NOIR provides manual mail-client invitation links and does not automatically send invitation emails. Projects retain up to 20 previous versions and 100 activity events. Feedback is deliberately submitted by users and linked to their account for abuse prevention; the owner can read it. Aggregated AI analytics retain the existing 90-day window and exclude full message bodies. Confirm other existing retention settings before publishing a final policy.

Prototype content runs in an opaque-origin sandbox with restricted network and navigation permissions. Never enter passwords or personal data into generated prototypes. Generated documents can contain mistakes. PDF export uses flattened page images.

Contact/support and account-data deletion requests need an operational owner process before expansion. No sale of personal data or new third-party advertising analytics is introduced by this update.
